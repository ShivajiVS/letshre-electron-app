# Release checklist

Unit and e2e tests don't cover the OS shell, real touchpads, real monitors or real accounts. Run these on the installed build (from `release/`, or the draft release's installer), not `pnpm dev`, against the UAT interview site. Copy this page into the release PR or issue and tick it there.

## Before you start

- [ ] **agent.exe freshness:** `pnpm run build:agent` ran after the last change to `agent.py`; `pnpm run dist` didn't refuse. In the installed app's log there is no `[agent] source_sha … does not match` error, and the security check's deep scan card isn't stuck on unverified (`preflightVerdict.js` refuses an agent whose hash differs from `resources/agent.build.json`).
- [ ] `.env` beside the installed executable points at the UAT hosts over https (`scripts/check-env.js` refuses anything else unless `ALLOW_DEV_ENV=1`).
- [ ] The version at the bottom of the security check page matches `package.json`.

## Machines

Run every check on at least the rows marked for it. One machine can cover several rows (a Windows 11 touchpad laptop with a second monitor and a standard account covers four).

| Row  | Setup                                                                          |
| ---- | ------------------------------------------------------------------------------ |
| W10  | Windows 10 22H2                                                                |
| W11  | Windows 11 23H2 or later                                                       |
| TP   | Laptop with a precision touchpad (3/4-finger gestures on)                      |
| MM   | Two monitors connected (extended), then Duplicate mode                         |
| STD  | Standard (non-admin) Windows user                                              |
| ADM  | Administrator Windows user                                                     |
| L10N | Non-English Windows display language (e.g. German or Hindi)                    |
| MAC  | macOS (only once macOS builds are enabled, see [release.md](release.md#macos)) |

## Checks

| Check                               | Rows             | Steps                                                                                                                                                                 | Expected                                                                                                                                                                                                                                            |

## After

- [ ] Every violation you caused appeared once in the site's proctoring log (no duplicates after page reloads).
